# Feature 001 — Portal Web G2

## Objetivo

Como visitante, quero navegar pelo Portal do Recreio Arcade para consultar jogos aprovados, seus detalhes e os rankings publicados pela API da plataforma.

## Requisitos

- O catálogo mostra apenas jogos com estado `aprovado`.
- Cada card mostra nome, autores, tema, nível e nota média/votos quando fornecidos pela API.
- A tela de detalhe mostra descrição, mecânica, controles, versões, feedback e taxa de acerto por tema.
- O Portal não calcula os rankings; apenas apresenta os dados recebidos.
- O Portal deve funcionar com dados mockados enquanto a API oficial não estiver disponível.
