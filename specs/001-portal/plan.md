# Plan — Portal Web G2

- React + TypeScript + Vite.
- React Router para navegação.
- Cliente HTTP centralizado em `web/src/api.ts`.
- URL da API configurável por `VITE_API_BASE_URL`.
- Design tokens inspirados no G3: `#050510`, cyan, amarelo, magenta, verde e tipografia monoespaciada.
- Nenhuma regra de ranking deve ser duplicada no frontend.
